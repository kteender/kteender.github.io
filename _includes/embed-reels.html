00:03:00 - 00:25:10: Juice Drop. Music video. I created all visuals. The character animation was created using my custom 2.5D mocap Maya plugin. Audio by Jeff Schulthies. Vocals by Dimitri Beshkov.

00:25:11 - 00:32:22: Traveling ballet combination. Keyframe exercise. Created based on reference from former professional ballet dancer and current aerospace engineer Marie Tender. I modified the Stewart rig from Animation Mentor with blendshapes to achieve the correct shape for dancing en pointe. Other than the rig, I created all visual aspects of this shot.

00:32:23 - 00:45:16: Welcome to the Sideshow. Animated monologue. I created all visuals. The character animation was created using my custom 2.5D mocap Maya plugin. The props (chair, desk, etc.) and backgrounds are drawn by hand with India ink. I also performed all the motion capture. The primary voice is my voice.

00:45:17 - 00:50:23: Youth Group 4. Cinematic sequence created using Unity. I created this shot as part of an 8-minute film using Unity's Timeline and Cinemachine. I performed motion capture cleanup in MotionBuilder and character modeling in Maya. For more information, see a pipeline post on my blog.

00:50:24 - 00:58:15: Midland Safari Putt-Putt. Animated short. Created with a 2.5D animation technique in Autodesk Maya, which I later expanded upon to create the work you see in Juice Drop, Christmas Rose, and Sewer Issue. Animation is keyframed. For more information, see a pipeline post on my blog.

00:58:16 - 01:05:17: The Illinois Basin. Freelance scientific animation. Excerpt from one of four animations created for the Illinois State Geological Survey to demonstrate geological concepts related to carbon sequestration. As part of the project, I independently studied geology concepts in order to accurately represent them visually. For information about the outlines rendering technique used in this shot, see my toon outlines post on my blog.

01:05:18 - 01:24:00: Sewer Issue. Animated short. I created all visuals. The character animation was created using my custom 2.5D mocap Maya plugin. I also performed all the motion capture. Audio by Jeff Schulthies.
